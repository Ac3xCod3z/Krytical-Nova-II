For using planar reflections-drag PlanarReflection.cs on water plane.(For URP-URP_PlanarReflection.cs; choise your plane as offset target)

Note what starting Unity 6(6.1) URP planar reflections was replaced with fake reflections due to unity changes:
it is not accurate but significant cheaper-so if you are using Unity 6.1+ with URP-no need to add script, it is not used.

For using with URP-unpack URP shaders.unitypackage first. If you are using Unity 6.1+ unpack URP6.1 shaders.unitypackage next

Water mask channels:
R-caustics
G-sparkles
B-foam
