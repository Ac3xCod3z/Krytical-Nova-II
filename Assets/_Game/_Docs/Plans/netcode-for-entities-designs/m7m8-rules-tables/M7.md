  W1 L137 "deferred (Q21)").

### Risk: **HIGH**. Moves items into the Pack and Creds into the wallet, writes two ledger kinds, and is the item-move
path between players (one drops, another picks up): a double pickup or a pickup after despawn duplicates items.

(WorldDrop 331 lines, WorldDropPool 100, TakenDropVisual 65, PlayerLoot 186) + 4 reader files. L if Entities Graphics
rendering is done in the same step.

tick), server-only cap/despawn system. Pickup and drop as two more discrete requests in the `PlayerRequestSystems` style
(`BodyOf(..., CallKind.Items)` -> unchanged `PlayerLoot.ServerPickup`/`ServerDrop` on the server body -> reply), the Pack
follows through the existing `PackCellRpc`; add an owner-only Creds mirror like `OwnerFlux`. The fly-to-hand effect is a
small owner/observer event at despawn. Test: two clients, a drop held for one, refused for the other, taken after 20 s,
