# M5.5c: the NGO rules table for `EcsHostileBrain` (DOTS 16, 6 Nov 2026)

`EcsHostileBrain` is the MonoBehaviour on a Hostile's hidden server body that implements `IHostileBrain`
(`Hostiles/Runtime/IHostileBrain.cs:10-35`), so `HostileNet` drives the entity brain exactly as it drives Emerald through
`HostileBrainLink` (`Hostiles/Emerald/Runtime/HostileBrainLink.cs`). Callers in NGO (`HostileNet.cs`): `SetAwake` :295, :312, :341;
`SetHome` :296, :313; `Calm` :337 (going to sleep); `Configure` :377; `Target` :503 (the threat note, H18). Nothing in the game calls
`Aggro` today (graphify + grep: no caller outside the brains).
