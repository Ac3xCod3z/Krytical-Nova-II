# The Stirring Well

**Cessation (Null).** Map scene: `Cessation_Run_TheStirringWell`. This folder is the place's own: its kit, this brief, and its concept art.

The full text, with the region kit and how the doc is read, is `Assets/_Game/_Docs/Design/Zone-Build-Kits.md` (in the Encyclopedia's Library); the Atlas card it builds on is `Design/World-Atlas.md`. Sizes follow `Design/16_world_scale.md`: a person is 1.8 m and trees are their real height.

## What is in this folder

- `Kit/`: the prefabs this place is built from, as variants of the Synty ones, already at world scale (Buildings 1, Ground 5, Props 7). What the whole region shares is in `../_RegionKit/`. Place from here, not from `Assets/Synty`.
- `Concept/Reference/` (where this place has one): the owner's finished-look mockup from the Figma World Atlas.
- `Concept/Owner/`: **your concept art goes here.** Name it `<what it shows>_<number>.png` (for example `Gate_01.png`); anything in this folder is yours and no tool writes to it.

## The brief

**Run: The Stirring Well** (3 floors). Bore Rim (a ring gallery round a 40 m shaft), the Descent (a spiral ramp 80 m down the shaft wall), the Listening Chamber (a 60 m cavern where the floor breathes). Down toward whatever stirs beneath Nova; its nature stays open (Lore Bible section 10). Assets: Sci-Fi Worlds `SM_Env_Core_Shell_*`, `SM_Bld_Core_Vent_Tunnel_*`; Dungeon `SM_Env_Cave_Large_*`, `SM_Env_SpiralStairs_*`; Dungeon Realms `SM_Env_Hell_Ring_*`, `SM_Env_Lava_Flow_*` recoloured crimson.
