# The Disassembly

**Cessation (Null).** Map scene: `Cessation_Run_TheDisassembly`. This folder is the place's own: its kit, this brief, and its concept art.

The full text, with the region kit and how the doc is read, is `Assets/_Game/_Docs/Design/Zone-Build-Kits.md` (in the Encyclopedia's Library); the Atlas card it builds on is `Design/World-Atlas.md`. Sizes follow `Design/16_world_scale.md`: a person is 1.8 m and trees are their real height.

## What is in this folder

- `Kit/`: the prefabs this place is built from, as variants of the Synty ones, already at world scale (Buildings 2, Props 4). What the whole region shares is in `../_RegionKit/`. Place from here, not from `Assets/Synty`.
- `Concept/Reference/` (where this place has one): the owner's finished-look mockup from the Figma World Atlas.
- `Concept/Owner/`: **your concept art goes here.** Name it `<what it shows>_<number>.png` (for example `Gate_01.png`); anything in this folder is yours and no tool writes to it.

## The brief

**Run: The Disassembly** (2 rooms). The Line (a 90 m conveyor hall, machines being taken apart in sequence), then the Press (a 40 m square chamber under a moving crusher). Where the Hegemony once broke machines for parts; the machines remember the sequence. Assets: Sci-Fi Space `SM_Bld_Floor_Large_Walkway_*`, `SM_Prop_MedicalArms_*` as dismantling arms; Cyber City `SM_Prop_Robotic_Needle_Arm_*`, `SM_Prop_Robot_Posed_Hanging_*`; Dungeon `SM_Env_Trap_Grinder_*`.
