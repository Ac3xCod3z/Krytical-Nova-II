# Silo 12

**Meridian Sprawl (Hegemony).** Map scene: `MeridianSprawl_Run_Silo12`. This folder is the place's own: its kit, this brief, and its concept art.

The full text, with the region kit and how the doc is read, is `Assets/_Game/_Docs/Design/Zone-Build-Kits.md` (in the Encyclopedia's Library); the Atlas card it builds on is `Design/World-Atlas.md`. Sizes follow `Design/16_world_scale.md`: a person is 1.8 m and trees are their real height.

## What is in this folder

- `Kit/`: the prefabs this place is built from, as variants of the Synty ones, already at world scale (Buildings 68, Ground 4, Props 11). What the whole region shares is in `../_RegionKit/`. Place from here, not from `Assets/Synty`.
- `Concept/Reference/` (where this place has one): the owner's finished-look mockup from the Figma World Atlas.
- `Concept/Owner/`: **your concept art goes here.** Name it `<what it shows>_<number>.png` (for example `Gate_01.png`); anything in this folder is yours and no tool writes to it.

## The brief

**Run: Silo 12** (2 floors). Grain Deck (circular, 40 m across, 20 m tall), then the Munitions Cache below (60 × 30 m vault). Harvester-bots turned sentries; the silo was never only for grain. Assets: Sci-Fi Worlds `SM_Bld_Pod_Silo_*` interior, `SM_Bld_Platform_*` decks, grain heaps from `SM_Env_Ground_Mound_*` (Meadow Forest) in gold; the cache: `SM_Prop_Crate_Military_*` (Sci-Fi City), `SM_Prop_Missile_*` (Sci-Fi Space), `SM_Prop_Turret_Small_Floor_*`.
