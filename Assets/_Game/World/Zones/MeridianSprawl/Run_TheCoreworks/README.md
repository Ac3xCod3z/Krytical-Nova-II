# The Coreworks

**Meridian Sprawl (Hegemony).** Map scene: `MeridianSprawl_Run_TheCoreworks`. This folder is the place's own: its kit, this brief, and its concept art.

The full text, with the region kit and how the doc is read, is `Assets/_Game/_Docs/Design/Zone-Build-Kits.md` (in the Encyclopedia's Library); the Atlas card it builds on is `Design/World-Atlas.md`. Sizes follow `Design/16_world_scale.md`: a person is 1.8 m and trees are their real height.

## What is in this folder

- `Kit/`: the prefabs this place is built from, as variants of the Synty ones, already at world scale (Buildings 5, FX 1, Props 10). What the whole region shares is in `../_RegionKit/`. Place from here, not from `Assets/Synty`.
- `Concept/Reference/` (where this place has one): the owner's finished-look mockup from the Figma World Atlas.
- `Concept/Owner/`: **your concept art goes here.** Name it `<what it shows>_<number>.png` (for example `Gate_01.png`); anything in this folder is yours and no tool writes to it.

## The brief

**Run: The Coreworks** (3 floors). Processing Deck (70 × 50 m), the Bore Shaft (a 30 m wide vertical drop circled by a ramp, 60 m deep), the Core Chamber (a 50 m dome). The extraction bore itself: soul-light leaking from every seam. Assets: Sci-Fi Worlds `SM_Env_Core_*`, `SM_Env_Core_Shell_*`, `SM_Env_Core_Strut_*`, `SM_Bld_Core_Vent_*`; Sci-Fi Space `SM_Bld_Floor_Large_Walkway_*`, `SM_Prop_Detail_Pipe_*`; `FX_Core_*` in the chamber.
