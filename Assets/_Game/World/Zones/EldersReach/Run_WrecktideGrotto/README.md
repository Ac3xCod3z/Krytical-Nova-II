# Wrecktide Grotto

**Elders-Reach (Covenant).** Map scene: `EldersReach_Run_WrecktideGrotto`. This folder is the place's own: its kit, this brief, and its concept art.

The full text, with the region kit and how the doc is read, is `Assets/_Game/_Docs/Design/Zone-Build-Kits.md` (in the Encyclopedia's Library); the Atlas card it builds on is `Design/World-Atlas.md`. Sizes follow `Design/16_world_scale.md`: a person is 1.8 m and trees are their real height.

## What is in this folder

- `Kit/`: the prefabs this place is built from, as variants of the Synty ones, already at world scale (Ground 10, Props 5). What the whole region shares is in `../_RegionKit/`. Place from here, not from `Assets/Synty`.
- `Concept/Reference/` (where this place has one): the owner's finished-look mockup from the Figma World Atlas.
- `Concept/Owner/`: **your concept art goes here.** Name it `<what it shows>_<number>.png` (for example `Gate_01.png`); anything in this folder is yours and no tool writes to it.

## The brief

**Run: Wrecktide Grotto** (2 rooms). Wreck Cavern (60 × 40 m sea cave, broken longships wedged in the rock), then the Tide Hall (a flooded hall of drowned warriors, 40 × 30 m). Assets: Dungeon `SM_Env_Cave_Large_*`, `SM_Env_Stalactite_*`, `SM_Env_Sewer_Water_*` as tide pools; Viking Realm `SM_Prop_Boat_Destroyed_*`, `SM_Prop_Barnacle_*`; `SM_Prop_ShipWreck_*`.
