# Howlstone Crypts

**Elders-Reach (Covenant).** Map scene: `EldersReach_Run_HowlstoneCrypts`. This folder is the place's own: its kit, this brief, and its concept art.

The full text, with the region kit and how the doc is read, is `Assets/_Game/_Docs/Design/Zone-Build-Kits.md` (in the Encyclopedia's Library); the Atlas card it builds on is `Design/World-Atlas.md`. Sizes follow `Design/16_world_scale.md`: a person is 1.8 m and trees are their real height.

## What is in this folder

- `Kit/`: the prefabs this place is built from, as variants of the Synty ones, already at world scale (Ground 24, Props 27). What the whole region shares is in `../_RegionKit/`. Place from here, not from `Assets/Synty`.
- `Concept/Reference/` (where this place has one): the owner's finished-look mockup from the Figma World Atlas.
- `Concept/Owner/`: **your concept art goes here.** Name it `<what it shows>_<number>.png` (for example `Gate_01.png`); anything in this folder is yours and no tool writes to it.

## The brief

**Run: Howlstone Crypts** (3 floors). Barrow Halls (long galleries of burial niches), the Hall of Kings (a 60 × 30 m frozen hall of seated stone kings), the Deep Cairn (a round pit 40 m across, a spiral stair down to the last king). Assets: Dungeon `SM_Env_Ceiling_Stone_Curved_*`, `SM_Env_Statue_*`, `SM_Env_SpiralStairs_*`, `SM_Env_Stalagmite_*`; Dungeon Realms `SM_Bld_Ruin_Pillar_*`; Viking Realm `SM_Env_Icicle_*`, `SM_Prop_Throne_*`.
