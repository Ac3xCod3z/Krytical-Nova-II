# Twelve Sky 2 — Module 06: PvE Grind & Progression

## 1. The core PvE loop
Twelve Sky 2 uses a classic grind-driven progression model:

Find appropriate monsters
→ Kill efficiently
→ Gain EXP
→ Gain Silver/items/materials
→ Upgrade character
→ Move to stronger hunting area.

## 2. Early game
The official Classic guide places levels 1–20 around the outskirts of the faction castle.

Players learn basic combat skills and use monster hunting to establish their initial build.

## 3. Field Champions
Field Champion monsters are stronger targets that can provide uncommon-rank items or Fortune Pouches.

This creates a simple decision:
Normal mobs = consistent EXP/resources.
Champions = higher-risk target hunting for better rewards.

## 4. Dungeon progression
The Classic leveling guide moves characters into increasingly difficult dungeon groups as level rises.

Examples include:
- Kipaku Fortress / Abiano Tomb.
- Hisakata Caverns / Nikusu Tomb.
- Aiyoku Shrine / Houka Caves.
- Later high-level faction dungeons.

## 5. Higher-level PvE
At level 90+, the Classic guide opens another tier of dungeon content through Yanggok Valley portals.

The pattern is:
Open new region → stronger monsters → better rewards → stronger character requirements.

## 6. Boss progression
Bosses become important because later systems use boss drops/materials to create or improve high-end equipment and progression items.

## 7. PvE is connected to PvP
PvE is not an isolated endgame.

It produces:
- EXP.
- Silver.
- Equipment.
- Refinement materials.
- Crafting materials.
- Contribution/class progression.
- Resources used to prepare for PvP.

## 8. Faction infrastructure can modify the grind
Current Faction Leadership documentation describes castles that increase:
- PvM CP.
- Silver from PvM.
- EXP from PvM.

This means faction control can directly change the efficiency of the PvE economy.

## 9. Design takeaway
The grind is deliberately cyclical:

Kill → Earn → Upgrade → Hunt stronger → Enter better content → Earn better resources → Prepare for PvP.
