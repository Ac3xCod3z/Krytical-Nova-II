## The complete loop

BUILD
→ GRIND
→ UPGRADE
→ PvP
→ EARN CP / CLASS / RANK
→ WAR
→ FACTION PROGRESSION
→ BETTER RESOURCES
→ BETTER BUILD
→ REPEAT

## Most important systems by dependency

1. Character stats/progression
2. Combat skills
3. Equipment progression
4. PvE grind
5. PvP
6. Faction/wars
7. Pets
8. Mounts
9. Economy/rank/endgame systems

The lower systems are intentionally connected to the higher ones instead of functioning as isolated features.
