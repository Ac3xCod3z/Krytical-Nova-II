# Twelve Sky 2 — Module 09: Economy, Rankings & Endgame

## 1. Main currencies/resources
The game's long-term systems revolve around:
- Silver.
- Contribution Points (CP).
- Class Points.
- EXP.
- Enhancement/refinement materials.
- Event-specific materials.

## 2. Silver
Silver supports:
- NPC services.
- Equipment progression.
- Upgrades.
- Combination/enhancement costs.
- Faction infrastructure.

## 3. Contribution Points
CP connects personal activity to faction/social progression.

CP can be earned through PvE/PvP activities and is used in high-level systems.

## 4. Class Points
Class Points are earned through designated PvP activities, particularly Holy Stone Battles, and feed the Class System.

## 5. Hero Rank
Hero Rank is a weekly competition within each faction.

Players gain Hero Points from:
- Wars.
- PvP activities.
- Special objectives.
- Monster hunting.
- Holy Stone participation.

The top ranks receive CP rewards.

## 6. Equipment endgame
The endgame equipment ladder includes:
- Reinforcement.
- Combination.
- WarLord tiers.
- Requiem.
- Refinement.
- Set bonuses.
- Specialized high-end materials.

## 7. Rebirth
Rebirth acts as a prestige/progression gate for advanced systems.

Higher Rebirth levels open access to stronger content and equipment systems.

## 8. Endgame activity loop
The mature Twelve Sky 2 loop is:

Grind PvE
→ Earn EXP/Silver/materials
→ Improve gear
→ Participate in PvP
→ Earn CP/Class/Hero rewards
→ Participate in faction wars
→ Gain access to stronger progression
→ Improve build
→ Repeat.

## 9. Why the system retains players
The game does not rely on one progression bar.

It stacks multiple goals:
- Character level.
- Rebirth.
- Gear enhancement.
- Gear refinement.
- Pet optimization.
- Mount optimization.
- Class progression.
- Hero Rank.
- Faction status.
- Territory control.

That creates multiple reasons to keep playing even after reaching a normal level cap.
