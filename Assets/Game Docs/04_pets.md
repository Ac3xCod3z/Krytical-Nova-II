# Twelve Sky 2 — Module 04: Pets

## 1. Pet role
Pets are an additional character-power layer rather than merely cosmetic companions.

They add abilities/stat effects that sit on top of the character's normal build.

## 2. Acquisition
Current Reborn documentation shows Pet Jade Chests can contain:
- Epic Pet Chest.
- Requiem-related materials.
- Pet ability-removal items.
- High-end skill materials.

An Epic Pet Chest randomly grants an Epic Pet.

## 3. Pet ability customization
Current documentation references Cat Eye and Mammon Stones as sources of additional pet abilities, with corresponding Oblivion Stones used to remove those ability sets.

This creates:
Pet acquisition → Ability modification → Build optimization.

## 4. Legendary/high-end pet architecture
The modernized system includes higher-end pet progression and special pet skill interactions.

The important design pattern is randomized acquisition followed by deterministic player optimization.

## 5. Pet combat identity
Pets can add:
- Additional offensive effects.
- Defensive effects.
- Special skill interactions.
- Build-specific utility.

## 6. Design takeaway
The pet system is effectively a secondary build:
Character build + Pet build = final combat package.
